# GameBoyAdvance Music Player

This is a personal project where I tried to make a generic music player for the GameBoyAdvance using Butano Engine. 
I also wanted to try to implement some game patterns even if they where overkill for this project, this is why some 
things are more complicated than they should be.


Made with Butano Engine by GValiente

Thanks to VVV Trippin'you for letting me use his music for this project.
